# JavaScript Beginner Practice Problems

A collection of 50 beginner-friendly JavaScript practice problems covering variables, input/output, conditionals, logical operators, loops, nested loops, and arrays, plus a few challenge problems. These exercises are designed to strengthen your JavaScript fundamentals and problem-solving skills before moving on to functions.

## Here are some practice problems you can solve using a foreach loop that starts easy and gets progressively harder

## Beginner

1. Print every number in an array.
2. Print every name in an array.
3. Print each fruit in uppercase.
4. Find the sum of all numbers.
5. Count how many items are in the array.

### Intermediate

1. Find the largest number in an array.
2. Count how many numbers are even.
3. Print only names that start with the letter "A".
4. Count how many vowels are in an array of letters.
5. Create a new array where each number is doubled.

### Challenge

1. Calculate the average of all numbers in an array.
2. Find the longest word in an array.
3. Count how many students passed (mark ≥ 50).
4. Print all duplicate values in an array.
5. Count how many times each word appears.
